Invitación interactiva de Pablo - versión HTML directo

Cómo usar:
1. Abre index.html en un navegador.
2. La página funciona como experiencia paso a paso.
3. Al final se puede copiar la respuesta o generar una captura PNG con lo elegido.

Cambios de esta versión:
- Se eliminó la selección de vibra del plan.
- Se eliminó el botón interno de Empezar.
- Se eliminó la sección de referencia archivada.
- La aceptación ahora tiene un botón "Sí, acepto" y un botón "No, no me interesa" que se escapa al intentar presionarlo.
- Se agregaron más opciones de comida.
- Se agregó opción para escribir otra comida personalizada.
- Se agregaron más opciones de plan.
- Se agregó opción para escribir otro plan personalizado.
- Se eliminaron WhatsApp, correo y calendario.
- El final solo permite copiar respuesta o generar una captura.

Nota importante:
La página no guarda ni envía respuestas automáticamente. Para que Pablo vea lo elegido, la persona debe copiar la respuesta o enviarle la captura generada.
